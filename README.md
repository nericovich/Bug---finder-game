# 🤖 AI-Powered Python Debugging Trainer

Интерактивный тренажер для отладки кода на Python, использующий **Groq API** для быстрой генерации и проверки заданий в реальном времени.

---

## 🚀 Ключевые возможности

- **Динамическая генерация задач:** Каждое задание создается нейросетью *на лету*, что обеспечивает бесконечное разнообразие.
- **Выбор тем:** Пользователь может выбрать конкретную категорию логических ошибок для тренировки (например, "работа со списками", "рекурсия").
- **Интеллектуальная проверка:** Решение пользователя анализируется с помощью LLM, которая дает подробный фидбэк и позволяет улучшать код после первой проверки.
- **Отслеживание прогресса:** Интерфейс отображает историю решенных и нерешенных задач.

## 🛠️ Установка и запуск

Для работы приложения необходимо установить зависимости, настроить API-ключ Groq и запустить веб-сервер.

---

### 1. Предварительные требования

- Python **3.8+**
- **Groq API key**: обязательная переменная окружения `GROQ_API_KEY`.

---

### 2. Настройка Groq API

> ⚠️ **ВАЖНО:** Для работы генератора заданий и проверки кода необходим активный ключ от Groq.

- Получите ключ на [Groq Console](https://console.groq.com/).
- Установите переменную окружения в терминале:

```bash
export GROQ_API_KEY="your-groq-api-key"
```
### 3. Установка зависимостей

```bash
python3 -m pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python3 app.py
```
После запуска откройте в браузере адрес: http://127.0.0.1:5000
