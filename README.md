# 🤖 AI-Powered Python Debugging Trainer

Интерактивный тренажер для отладки кода на Python, использующий **локальную LLM** для генерации и проверки заданий в реальном времени.

---

## 🚀 Ключевые возможности

- **Динамическая генерация задач:** Каждое задание создается нейросетью *на лету*, что обеспечивает бесконечное разнообразие.
- **Выбор тем:** Пользователь может выбрать конкретную категорию логических ошибок для тренировки (например, "работа со списками", "рекурсия").
- **Интеллектуальная проверка:** Решение пользователя анализируется не по тестам, а с помощью LLM, которая дает "человекоподобный" фидбэк.
- **Двойной контроль качества:** Система автоматически проверяет каждое сгенерированное задание, чтобы убедиться, что оно действительно содержит ошибку.
- **Отслеживание прогресса:** Интерфейс отображает историю решенных и нерешенных задач.

## 🛠️ Установка и запуск

Для работы приложения необходимо выполнить **два основных шага**: установить зависимости Python и запустить веб-сервер.
Для генерации задач и проверки решений требуется работающий Hugging Face API с переменной окружения `HUGGINGFACE_API_TOKEN`.

---

### 1. Предварительные требования

- Python **3.8+**
- **Hugging Face API token**: обязательная переменная `HUGGINGFACE_API_TOKEN`.
- **Модель Hugging Face**: опционально `HUGGINGFACE_MODEL_ID` для выбора нужной модели.

---

### 2. Настройка Hugging Face API

> ⚠️ **ВАЖНО:** Если вы хотите, чтобы задачи генерировались динамически через Hugging Face, задайте `HUGGINGFACE_API_TOKEN`.

- Получите токен на https://huggingface.co/settings/tokens.
- Установите переменные окружения:

```bash
export HUGGINGFACE_API_TOKEN="<your-token>"
export HUGGINGFACE_MODEL_ID="gpt2"
```

Если хотите использовать другую модель, замените `gpt2` на нужный идентификатор, например `meta-llama/Llama-2-7b-chat-hf`.

### 3. Установка зависимостей

```bash
python3 -m pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python3 app.py
```
